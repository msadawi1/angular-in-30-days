# Debugging & DevTools

## Browser DevTools

- You can use the `sources` option of the DevTools to see the original code using source-mapping.
- You can add breakpoints to the code while the browser is executing it for debugging, which acts like a normal IDE debugger (dive into, step into, break, see values etc.)

## Angular DevTools (Chrome Extension)

- Used to inspect the component tree of the application, modify component states, see injection tree and do performance analysis
- Has three tabs:
1. Components (Component Tree & States)
2. Profiler (Performance)
3. Injector Tree (DI)
