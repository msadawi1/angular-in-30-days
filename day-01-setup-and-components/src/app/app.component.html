Angular Architecture:

Angular has four parts:

  1. Components: resuable UI elements bundled using TS, CSS & HTML
  2. Services: resuable logic shared between components
  3. Modules: a group of related components & services
  4. Templates: HTML templaets with special Angular syntax

Components

Components in Angular have three parts:

  1. HTML Template
  2. CSS Styles
  3. TypeScript Component Class delcared with `Component` decorator
Note: templates and styles can be either inline or external using a file URL
